## Overview

A browser-only health-learning toolkit: label B-mode ultrasound images for ML-style datasets, run a transparent rule-based symptom checker, and use **offline data analysis** to verify that triage rules behave as labeled. Images never leave the device.

## What I Built

1. **Ultrasound annotation tool** — boxes / polygons, zoom/pan, **COCO / YOLO** export.  
   [Open tool →](/projects/ultrasound-tool)
2. **AI Doctor** — bilingual symptom checker, dental starter dataset, B-ultrasound learn/compare/quiz.  
   [Open AI Doctor →](/aidoctor/)
3. **Analysis tab** — knowledge-base coverage, dental class distribution, and 20 labeled triage cases (expected vs actual + pass rate).

## Tech & Skills

Vanilla JS + Canvas, annotation, COCO/YOLO, rule-based triage, dataset manifests, test-driven rule validation.

## Outcomes

- Working annotation + checker + ultrasound learning modules  
- Openly licensed dental starter set (healthy / caries / gingivitis)  
- Offline analysis with visualized distributions and a triage test suite  

## Honest limits

Educational demo only — not a diagnosis tool. Analysis pass rate measures **consistency with a student-built labeled set**, not clinical accuracy.
